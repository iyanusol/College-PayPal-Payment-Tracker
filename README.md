## 📌 Project Overview
This project analyzes **PayPal payment transactions for college application services** between **2023 and 2024**, transforming raw payment data into **business-ready insights** using **Python, SQL, Power BI, and DAX**.

The goal was to understand:
- Revenue performance over time  
- Product-level profitability  
- Payment success vs refunds  
- Market mix (domestic vs international)  
- Key operational KPIs for decision-making  

This was a full **end-to-end analytics workflow**, from raw dataset to executive dashboard.

---

## 🧱 Raw Data
The project started with raw PayPal transaction data containing:
- Payment amounts (captured & refunded)

## 🔍 Key Insights
- Revenue is highly concentrated in a small number of products
- Domestic payments account for the majority of total transactions
- Payment success rates are strong, with minimal refunds
- Clear seasonal trends appear in payment volume
- Average transaction value remains stable across periods
